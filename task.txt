Дан массив товаров. Выведите их в виде таблицы с возможностью выбрать один товар
или отменить выбор.

Вот рабочий пример.

В этом задании используется CSS-фреймворк Bulma. Он уже установлен и подключен,
поэтому вы можете использовать его классы.

Весь код разместите внутри компонента `App` (не создавайте дополнительные компоненты).
Сохраняйте выбранный товар (`selectedGood`) в состоянии (по умолчанию выбрано «Jam»).
Отображайте название выбранного товара в заголовке `h1.title` (например, «Jam is selected»).
Кнопка «ClearButton» должна появляться в заголовке только тогда, когда выбран какой-либо товар.
При нажатии «ClearButton» выбор должен сбрасываться (установите пустую строку в `selectedGood`).
Если товар не выбран, в заголовке должна отображаться надпись «No goods selected».
У каждого товара должна быть кнопка «AddButton» для его выбора.
Одновременно можно выбрать только один товар.

Добавьте класс `has-background-success-light` к строке таблицы (`tr`), соответствующей выбранному товару.
Если товар уже выбран, кнопка «AddButton» для него отображаться не должна.
Для выбранного товара отображайте кнопку «RemoveButton», позволяющую отменить выбор.
